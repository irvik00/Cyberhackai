# Обнаружение фишинговых URL

Хакатон Cyberhackai / АВ Софт, октябрь 2026. Участница: **Simonenko_sa**.

Классификация сайтов по URL и сохранённому HTML: `1` — фишинг, `0` — безопасный сайт. Метрика — F1.

Полная таблица и история экспериментов — [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md).

## Модель

Ансамбль трёх ветвей:

1. **LinearSVC на URL и содержимом:** TF-IDF адреса, hostname, заголовка, текста, ресурсных хостов, HTML-тегов и числовые признаки.
2. **HistGradientBoostingClassifier:** структурные признаки URL и HTML.
3. **LinearSVC на исходном HTML и атрибутах:** слова и пары слов; первые 12 000 и последние 4 000 символов HTML.

Первые две ветви объединяются с весами 0.75/0.25. Полученный refined score смешивается с source score с весами 0.75/0.25 после масштабирования. Порог — **0.034253455073786174**. Параметры — [configs/external.json](configs/external.json).

Также используются однозначные совпадения URL/хостов, HTML-шаблоны и согласованные метки из внешних URL-датасетов. Поздние short/brand/URL-content коррекции в выбранное решение не входят.

Обучение: пять стратифицированных фолдов, seed 42; 63 998 строк после исключения двух конфликтующих URL. OOF F1 = **0.989380**, ошибок **508**: FP 186, FN 322.

## Полное обучение

Скачайте **`solution_external_verification.zip`** из раздела **Releases** и положите в родительскую папку репозитория. Это пакет данных и HTML-признаков для полного обучения.

```powershell
.\.venv\Scripts\python.exe reproduce.py train --bundle "..\solution_external_verification.zip"
```

В `_work/external/` подготавливаются входы и запускаются исходные скрипты обучения. Сохранённые model scores из пакета не используются. Итоговый CSV проверяется по SHA256 и записывается в `outputs/submission_external.csv`. Для повторного запуска укажите новую папку: `--workdir _work/external_2`.

Источники данных и запуск из исходных CSV/HTML — [docs/DATA.md](docs/DATA.md).

**Проверка:** быстрая сборка воспроизвела CSV без отличий. Полное повторное обучение из подготовленного пакета отдельно не прогонялось.
